# SyncDrive: UI for Rclone

**SyncDrive: UI for Rclone** brings the power of the `rclone` CLI to your device with a modern, intuitive graphical interface. Easily manage, sync, and back up data with cloud storage providers.

---

## 🖥️ Desktop Version
SyncDrive fully supports desktop platforms.

### Download the Desktop Version:
1. Go to the **[Releases](https://github.com)** section on the repository page.
2. Look for the **Latest** release.
3. Download the correct installer for your OS (Windows, macOS, Linux) under **Assets**.
4. Run the installer.

---

## 🚀 Key Features

* **Cloud Integration:** Connect to Google Drive, Dropbox, and others via secure OAuth 2.0 & PKCE.
* **Bi-directional Sync:** Set up sync pairs between local storage and the cloud.
* **Background Running:** Maintain stable file transfer tasks.
* **Advanced Remote Management:** Create, update, or delete configs inside the app.
* **Offline Security:** Store encrypted configurations locally.
